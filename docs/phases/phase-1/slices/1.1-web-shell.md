## Spec

### Mục tiêu

Dựng khung cho web để các slice sau chỉ việc gắn màn hình vào: router, layout có sidebar, bộ component shadcn/ui, API client và cách hiển thị lỗi dùng chung. Trang trạng thái API/DB của Phase 0 chạy trong khung mới.

### Trong phạm vi

- TanStack Router file-based, `routeTree.gen.ts` sinh bằng task `generate`
- Tailwind 4 + shadcn/ui, theme sáng
- Layout: sidebar (Dashboard, Contacts, Companies, Deals, Activities), header, vùng nội dung
- Trang Dashboard (trạng thái API/DB), trang giữ chỗ "Coming soon" cho 4 module, trang 404
- Trạng thái API nhỏ ở chân sidebar
- API client `api<T>()` + `ApiError`, default của TanStack Query
- Component lỗi dùng chung (có nút thử lại, request-id), toast cho lỗi của thao tác (Sonner)
- Devtools của Router và Query khi dev
- Giao diện tiếng Anh, đổi text tiếng Việt hiện có

### Ngoài phạm vi

- Login, xử lý 401 thật (slice 1.2). 1.1 chỉ để chỗ trong API client
- Màn hình nghiệp vụ, bảng dữ liệu (TanStack Table từ slice 1.3)
- Dark mode (backlog), i18n
- Sinh client từ OpenAPI

## Ghi chú khi implement

Những gì lệch khỏi plan trong lúc làm, và lý do.

- **Lỗi của health không dùng `ErrorState`:** API không kết nối được chính là trạng thái cần báo, nên card hiện `API: Unreachable, DB: Unknown` như mockup. `ErrorState` dùng làm `defaultErrorComponent` của router và cho các trang sau. Tiêu chí "Dashboard hiện `API: ok, DB: ok`" thành card hiện `Online` theo design.
- **Kích thước sidebar theo shadcn:** rộng 16rem (mockup 240px), ngăn kéo dưới 768px (mockup 720px). Giữ nguyên file sinh ra của shadcn.
- **shadcn CLI 4.23 (preset `radix-nova`):** lần đầu tạo nhầm thư mục `apps/web/@/` và import `cn` từ package `cn` vì không đọc được alias. Đã chuyển file vào `src/`, đổi import về `@/lib/utils`, thêm `paths` vào `apps/web/tsconfig.json` (chỉ cho CLI đọc). Bỏ `next-themes` (Sonner cố định theme sáng).
- **Font tự host** bằng `@fontsource-variable/geist`, `geist-mono` thay vì Google Fonts.
- **Devtools:** Router ở góc trái dưới, Query ở góc phải dưới (mockup để cả hai bên trái, sẽ đè nhau).
- **Giữ `App.tsx`** làm component bọc provider (QueryClient + Router) để `main.tsx` và test render cùng một cây.
- **Service `setup`** sinh thêm route tree (`@crm/web#generate`), để IDE thấy type ngay sau `make up`.
- **Lint:** tắt `react-refresh/only-export-components` cho `routes/` (plugin router tách component ra module riêng) và cho `components/ui/`, `hooks/` (file shadcn, cùng `react-hooks/set-state-in-effect`).
- **Test:** tắt code splitting của router khi chạy Vitest. Chunk route tải lười làm test chập chờn khi `make test` chạy cùng test api.
- **`NetworkError`:** `api()` bọc lỗi không có response thành `NetworkError` (abort thì để nguyên), để phân biệt mất kết nối với lỗi khác (lỗi render hiện "Something went wrong").
- **Bundle:** `index.js` 499 kB (158 kB gzip), devtools của TanStack không có trong bundle.

### Code review (`/code-review`, một vòng)

Đã sửa:

- Mọi lỗi không phải `ApiError` (cả lỗi render) bị báo "Can’t reach the server" → thêm `NetworkError`, lỗi khác hiện thông báo chung
- Body JSON hỏng làm mất status và request-id → parse lỗi thì giữ text
- "Try again" của trang lỗi route chỉ reset boundary → gọi `router.invalidate()` (component `RouteError`)
- Test phải nâng timeout vì route code-split → tắt code splitting khi chạy Vitest, bỏ timeout
- Toast của Sonner lọt sang test sau → `toast.dismiss()` sau mỗi test
- Trạng thái ở chân sidebar không focus được bằng bàn phím khi thu gọn → `tabIndex={0}`
- `application/problem+json` không được parse → nhận mọi kiểu `+json`

Không sửa:

- Sidebar không nhớ trạng thái thu gọn sau khi reload (shadcn ghi cookie nhưng Vite không đọc lại): chấp nhận, ít giá trị lúc này
- Toast tự động cho mọi mutation, chưa có cách tắt: chưa có form nào, thêm `meta` tắt toast ở slice 1.3 khi form hiện lỗi tại chỗ
- Input task `generate` chỉ có `src/routes/**`: turbo đã đưa phiên bản dependency của package vào hash, nâng router-cli thì cache tự đổi
